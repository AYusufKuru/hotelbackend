HotelCRM Backend — API Referansi
================================================================================
Base URL (gelistirme): http://127.0.0.1:8000

KIMLIK DOGRULAMA
--------------------------------------------------------------------------------
Tum /api/* CRUD uclari (asagidaki tablo kaynaklari) JWT gerektirir:
  Authorization: Bearer <access_token>

Herkese acik:
  POST /api/auth/login/     Girdi: {"username","password"}
                            Cikti: access, refresh, user { id, username, email }

  POST /api/auth/refresh/   Girdi: {"refresh"}
                            Cikti: access (ve ayarlara gore refresh)

Login endpoint'i degismedi: desktop /api/auth/login/ ile uyumludur (prefix: api/ + auth/ + login/).

VERI MODELI
--------------------------------------------------------------------------------
Iliskisel sema: backend/docs/hotelcrm.dbml (dbdiagram.io ile acilabilir).
Django modelleri hotelcrm uygulamasinda; tablo adlari hotelcrm_* prefix ile.

OZEL NOTLAR
--------------------------------------------------------------------------------
- invoices (DBML) -> Django modeli: OperationalInvoice
  API yolu: /api/operationalinvoice/
  (Stok envanterindeki inventory ile kod karismasin diye.)

- Django User (django.contrib.auth) kullanilir; DBML'deki ayri "users" tablosu yok.
  Rol/izin: Role, Permission, UserRole, RolePermission

REST KAYNAKLARI (ModelViewSet)
--------------------------------------------------------------------------------

  GET    /api/<kaynak>/           Liste
  POST   /api/<kaynak>/           Olustur
  GET    /api/<kaynak>/{uuid}/    Detay (PK cogu UUID; BigAutoField: integrationeventlog)
  PUT    /api/<kaynak>/{uuid}/    Tam guncelleme
  PATCH  /api/<kaynak>/{uuid}/    Kismi guncelleme
  DELETE /api/<kaynak>/{uuid}/    Sil
